1. Introduction to ArcadeVerse

ArcadeVerse is an advanced retro-gaming portal designed to operate entirely within the user's browser. It features zero dependencies, zero external images or audio files, and runs at a constant 60 FPS utilizing HTML5 Canvas and the Web Audio API.

Every sprite, animation frame, sound effect, and background music score is calculated procedurally in JavaScript at runtime. The portal represents a self-contained gaming system built on a custom Entity-Component-System (ECS) engine framework.

System Note: All game states, high scores, achievements, and custom player profiles are persisted client-side in localStorage.

2. 2D Entity-Component-System (ECS)

The core engine (engine.js) employs a lightweight, high-performance Entity-Component-System design pattern. This decouples data from logic, facilitating modular expansion.

  • Entity: A unique numeric identifier representing an object in the world.
  • Component: Plain structures carrying state data (e.g. Transform, Velocity, Sprite, Collider).
  • System: Logic processors that iterate over entities matching specific component masks (e.g. PhysicsSystem, RenderSystem).

Core Game Loop

The loop employs a fixed timestep update with a variable rendering interpolator to prevent physics tunneling and guarantee deterministic calculations across different monitor refresh rates.

// Pseudocode of the timestep loop
let lastTime = performance.now();
let accumulator = 0.0;
const dt = 1000.0 / 60.0; // 60 FPS update

function loop(time) {
    let elapsed = time - lastTime;
    lastTime = time;
    accumulator += elapsed;
    
    while(accumulator >= dt) {
        engine.update(dt);
        accumulator -= dt;
    }
    
    let alpha = accumulator / dt;
    engine.render(alpha);
    requestAnimationFrame(loop);
}

3. Physics & Bounding Box Collisions

The engine resolves static and dynamic collisions through Axis-Aligned Bounding Box (AABB) projections and Circle-to-AABB intersection resolutions.

AABB Intersection Equation

For two bounding boxes \(A\) and \(B\), defined by their min/max coordinate vectors, an intersection occurs if and only if:

\[ (A_{min.x} \le B_{max.x} \land A_{max.x} \ge B_{min.x}) \land (A_{min.y} \le B_{max.y} \land A_{max.y} \ge B_{min.y}) \]

Resolution

When an intersection is detected, the overlap vector is computed along both axes. The entity is projected back along the axis of minimum penetration, and its velocity along that axis is set to zero or multiplied by a coefficient of restitution (bounciness).

4. Audio Synthesis via Web Audio API

ArcadeVerse has no static audio assets. Sound effects are synthesized on-demand, and backing tracks are played via custom code scheduler nodes.

Custom Synthesizer Settings

The sound library employs envelopes to adjust frequency and gain parameters over time. An ADSR (Attack, Decay, Sustain, Release) envelope is used to sculpt sounds:

  • Laser: Expontential pitch sweep down from 1200 Hz to 200 Hz over 0.15s, using a sawtooth wave.
  • Explosion: Bandpass filtered white noise buffer modulated with an exponential amplitude decay.
  • Coin: Quick double-tone pitch shift (e.g. 987 Hz to 1318 Hz) using sine waves to generate a bright chiptune ring.

5. Pseudo-3D Racer Road Projection

The Synth Racer game generates curved highways and hills using a classic pseudo-3D perspective projection technique similar to classic arcade cabinets.

Projective Transformation

Points along the road curve are represented in 3D world space \((x, y, z)\) and projected onto the 2D screen coordinate space \((X, Y)\) using the equations:

\[ X = \frac{Width}{2} + \frac{x - Camera_x}{z - Camera_z} \times Focus \] \[ Y = \frac{Height}{2} - \frac{y - Camera_y}{z - Camera_z} \times Focus \]

Where Focus is the screen projection distance. Scenery sprites are rendered with a scale factor \(S\) proportional to distance: \(S = \frac{Focus}{z - Camera_z}\).

6. Procedural Data Systems & Structures

To establish a rich, responsive arcade experience, ArcadeVerse features deep data matrices and procedural math generators, including:

  • Wave Formation Logic: Mathematical curves defining enemy swarm trajectories, hitpoints, and speed scaling over time in Cosmic Void.
  • Defense Waypoint Grids: Navigational grid nodes directing invading squad paths and coordinate raycasting for defensive turrets in Neo-Defender.
  • Pseudo-3D Track Segments: Road elevation curves and curvature tables generating infinite procedural highway hills in Synth Racer.
  • Block Matrix Rotator: Matrix transposition algorithms managing piece states, wall-kick resolutions, and cascade multipliers in Block Cascade.
